Risks and context
    Method and reproducibility

    Every number on this page is read from files committed in this repository. Raw snapshots are hashed in data/MANIFEST.json; the offline rebuild recomputes every metric; the sampling plan was frozen with a SHA-256 before any sampled block was read.

    make reproduce && make test && make dashboard
    make sample-verify && make history-results

    Sources
    DefiLlama (volume, fees, revenue, TVL, stablecoins), Nearblocks daily charts, NEAR JSON-RPC (final state and archival reads), the NEAR Intents Explorer API, the pre-registered flow-test queries in sql/, Binance public market data, gov.near.org, and a full node we operate for block-by-block census data.

    Rating inputs and every post-freeze choice are dated in PREREG-ADDENDUM.md. The written report is REPORT.md.
